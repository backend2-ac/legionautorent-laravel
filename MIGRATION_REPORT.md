# Перенос LEGIONAUTORENT на Laravel / MySQL

Дата: 8 октября 2026. Отдельная копия: `D:\legionautorent-laravel`. Django: `D:\legionautorent.kz` сохранён. Источник публичной реализации — утверждённая чистая копия Django, commit `5f885d503290cfe3cb28f76c0b709b9055ce4459`. ## Перенесено

- Laravel 13.35.0, PHP 8.4, Filament 5.10.0, MySQL 8.4.11 нативно / 8.4.10 в проверенном локальном Docker.
- 91 автомобиль, 302 фото-записи, 364 скидки, 4 города, 5 исходных страниц и 5 новых SEO-записей системных страниц, 5 FAQ, 15 блоков, 8 секций, 7 пунктов меню; интерфейс дополнен, опубликованы 866 полных переводов KK/EN.
- 1 существующий пользователь, 3 роли, 120 разрешений и 80 связей ролей, 2 заявки. Пароль совместим с исходным Django-хешем; реальный вход проверен без сброса.
- 3893 медиафайла, 262181501 байт. Hero, шрифты и бренд сохранены; мастер hero побайтово совпадает с источником.
- Исходные идентификаторы, slugs, exact legacy_path, цены, доступность и утверждённые Title/description/H1/canonical сохранены. Переводы завершены; вместо исходной заглушки Павлодара опубликован текст. Все отличия от live перечислены в SEO_LIVE_COMPARISON.md.
- 32 публичных шаблона переведены на Blade; фронтенд не требует Python/Django. Импорт выполняется PHP-командой в пустую MySQL-базу.

Все 21 раздел админки перенесены в Filament. Доступны CMS-поля, галереи/тарифы/скидки/характеристики/переводы автомобиля, политика конфиденциальности, контакты/hero/партнёры, интерфейс/меню/секции, заявки/CSV, роли/пользователи. Автоматические производные новых фото, ограничения SEO/переводов, аудит и права проверены. Зависимые от заявок автомобили/города и используемые классы/марки защищены от удаления.

В MySQL сохранены отношения, уникальности и правила CASCADE/SET NULL/PROTECT. Используется utf8mb4_bin для точного переноса ключей; поиск явно остаётся нечувствительным к регистру.

## Docker и D

Образы, контейнеры и тома Docker Desktop хранятся в `D:\DockerData\wsl`; старый путь на C — junction. Сам Docker Desktop установлен на C. Контейнеры других проектов сохранены.

Кешированный mysql:8.4.11 на этом компьютере повреждён после прежней нехватки места: entrypoint оказался пустым. Общий образ не удалялся. Локальный стек использует отдельно загруженный официальный mysql:8.4.10; новая установка по умолчанию использует 8.4.11. Нативная разработка и все PHPUnit-тесты выполнены на 8.4.11.

Runtime Docker — отдельный том, snapshot монтируется только для чтения, public/media остаётся отдельной папкой D. APP_URL Docker задаётся через DOCKER_APP_URL. Файлы базы и медиа не удалялись при пересборках.

Проверка ffprobe выполнена в Docker; для нативных новых видео-загрузок потребуется настроенный FFPROBE_PATH. Ролик/кадры сохранены, скорость отрисовки любого телефона не гарантируется.
